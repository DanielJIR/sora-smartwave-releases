# SORA SmartWave releases

Windows installers and release notes for SORA SmartWave.

Download a version from [Releases](https://github.com/DanielJIR/sora-smartwave-releases/releases).
Prereleases are for owner functional testing. They are not stable Latest releases.
The installer runs per Windows user and preserves project files and account data.
SHA256SUMS.txt accompanies each installer. Installation is manual.

SmartWave requires its own SORA Platform permission for licensed operations.
Native project viewing and saving remain available without an active permission.
The initial 0.1.0 release candidate awaits Platform catalog provisioning and live
account tests; see its release notes before testing licensed operations.

Application source and the shared SORA Platform client are maintained separately.
This repository contains no account credentials, private datasets or source code.
